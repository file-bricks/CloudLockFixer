# Support

## Deutsch

- GitHub Issues & Bugtracker: <https://github.com/file-bricks/CloudLockFixer/issues>
- Dokumentation & Quellcode: <https://github.com/file-bricks/CloudLockFixer#readme>
- Sicherheitsrelevante Schwachstellen bitte vertraulich über GitHubs **Security Advisories** melden: <https://github.com/file-bricks/CloudLockFixer/security/advisories>
- Allgemeine Anfragen & Kontakt: `info@file-bricks.org`

### Hilfreiche Angaben für Fehlerberichte

- CloudLockFixer-Version (`cloudlockfixer --version`)
- Windows-Version (z. B. Windows 11 23H2 / 24H2)
- Betroffener Cloud-Sync-Provider (z. B. OneDrive, Google Drive, Dropbox, pCloud, Nextcloud)
- Art der Operation (Umbenennen, Verschieben, Löschen)
- Relevante Zeilen aus `%LOCALAPPDATA%\CloudLockFixer\cloudlockfixer.log` (ohne vertrauliche Pfade oder Dateiinhalte)

## English

- GitHub Issues & Bug Tracker: <https://github.com/file-bricks/CloudLockFixer/issues>
- Documentation & Source Code: <https://github.com/file-bricks/CloudLockFixer#readme>
- Security vulnerabilities should be reported confidentially via GitHub **Security Advisories**: <https://github.com/file-bricks/CloudLockFixer/security/advisories>
- General contact: `info@file-bricks.org`

### Helpful information for bug reports

- CloudLockFixer version (`cloudlockfixer --version`)
- Windows operating system version (e.g., Windows 11 23H2 / 24H2)
- Target cloud sync client (e.g., OneDrive, Google Drive, Dropbox, pCloud, Nextcloud)
- File operation attempted (rename, move, delete)
- Relevant log excerpts from `%LOCALAPPDATA%\CloudLockFixer\cloudlockfixer.log` (excluding confidential names or paths)

1. EXECUTIVE VALUE PROPOSITION
--------------------------------------------------------------------------------
CloudLockFixer (CLF-WDAS) is an autonomous Windows tray service and developer CLI
tool for delayed, non-blocking rename, move, and delete operations inside cloud-sync
folders (OneDrive, Dropbox, Google Drive, Box, iCloud, Nextcloud, pCloud, and
Synology Drive). It eliminates filesystem friction caused by the Windows Cloud
Files Mini-Filter (`cldflt.sys`) and syncing background engines through a reliable
queue-driven copy+delete fallback mechanism with bit-for-bit SHA-256 verification,
100% local-first zero-egress data isolation, and unprivileged user-mode execution.


2. TARGET AUDIENCE & STAKEHOLDER PERSONAS
--------------------------------------------------------------------------------
Persona 1: Desktop Power Users & Cloud Sync Workers
- Context: Work daily in local folders synchronized with OneDrive, Dropbox, or Google Drive.
- Pain Point: "File in use by another process" (EBUSY / WinError 32 / WinError 5) blocks
  renaming, moving, or cleaning up folders during active background sync cycles.
- Benefit: Silent, automatic delayed execution via system tray and Explorer context menu;
  queue and forget without manual retries or process kills.

Persona 2: Autonomous AI Coding Agents & Developer CLI Tools
- Context: LLM agents (Antigravity, Codex, Claude Code) and build scripts orchestrating
  automated workspace refactoring, file migrations, and cleanup.
- Pain Point: Scripted file operations fail abruptly when cloud sync engines hold transient
  file locks, corrupting automated test suites and agent worktrees.
- Benefit: Headless CLI (`clf add`, `clf run-now`, `clf list`, `clf retry-all`), plain text
  `queue.txt` interface, and structured `llms.txt` context for fail-safe automation.

Persona 3: DevOps & CI/CD Pipeline Automation Engineers
- Context: Multi-OS build matrices, scheduled automation runners, and developer workstations.
- Pain Point: Leftover build artifacts, locked test caches, and sync-lock race conditions
  causing non-deterministic build step failures.
- Benefit: Multi-step atomic operation chains (`op1 && op2 && op3`), deterministic task
  states (`pending`, `done`, `retryable`, `blocked`, `permanent`), and cross-platform
  compatibility across Windows, Linux, and macOS.

Persona 4: Enterprise Privacy & Compliance Auditors
- Context: Regulated enterprise environments subject to strict data governance and GDPR/DSGVO.
- Pain Point: File unlocking utilities often require kernel drivers, administrative elevation,
  or communicate with closed telemetry endpoints.
- Benefit: Zero outbound network egress (verified by static AST inspection), strictly
  unprivileged RunAsInvoker operation mode, and complete MIT-licensed transparency.

6. GOVERNANCE & RUNTIME INVARIANTS
--------------------------------------------------------------------------------
- INV-LOCAL-01: 100% Local-First & Zero-Egress. No outbound socket, HTTP, or telemetry traffic.
- INV-PRIV-02:  Unprivileged Execution. Runs strictly as user (RunAsInvoker); no UAC prompt.
- INV-SAFE-03:  Cryptographic Data Verification. Fallback copies verify bit-for-bit SHA-256 match.
- INV-ATOM-04:  Atomic Step Ordering. In chains, Step N executes only if Step N-1 succeeded.
- INV-RETRY-05: Configurable Retry Limits. Default fire-and-forget; configurable max retries.
- INV-NOTIF-06: Desktop Notification Contract. Emits tray toasts on permanent failures or blocks.
- INV-PROV-07:  Virtual Mount Guard. Never pauses virtual-mount providers (Google Drive, pCloud).
- INV-CONF-08:  Multi-Host Conflict Defense. Strict gitignore blocking of sync copies and locks.
- INV-CI-09:    Deterministic CI Guardrails. Matrix timeout-minutes (15/10/5) and cancel-in-progress.
- INV-SLA-10:   Bilingual Security Policy. 48-hour response SLA and 5-business-day triage commitment.
